Fleet overview

Health, version, nodes, pods and API latency of every cluster, checked in parallel the moment you open the app.

Needs attention

Crash-looping pods, nodes that aren't ready and failed jobs from all your clusters, in one list. One click opens the culprit.

Resource charts

CPU and memory per pod against its requests and limits, with history; node capacity and the busiest pods at a glance.

Cross-cluster tables

⌘-click two or more clusters and see the same resource across all of them in one live table, with a cluster column.

Production stands out

Every cluster carries its environment — prod, staging, dev — with a colored strip on top. On production, deleting or editing asks you to type the name.

Logs, shell, port-forward

Follow colored logs with search, open a shell in any container, forward ports from pods and services — all built in.

Edit & apply YAML

Live, always

Talks straight to your API servers with your kubeconfig. Your cluster data never touches our servers, and there's no telemetry. Updates arrive signed.

FAQ

Questions

Does Steerglass send my cluster data anywhere?

No. Steerglass talks directly from your computer to your Kubernetes API servers using your existing kubeconfig. Your cluster data never leaves your machine and there's no telemetry.

Which clusters and auth methods are supported?

Anything kubectl can reach: EKS, GKE, AKS, OpenShift, k3s, kind, minikube, Rancher and bare metal. Token, client-certificate, OIDC and exec credential plugins (gke-gcloud-auth-plugin, aws, kubelogin…) all work as they do in your terminal.

How is it different from Lens, k9s or Headlamp?

Steerglass is built for working across many clusters at once: their resources land side by side in one live table, and it stays fast on big clusters. Lens, k9s and Headlamp are great tools with strengths of their own — Helm and extensions, the terminal and in-cluster use. See our honest comparisons with Lens, k9s and Headlamp.

Do I need an account?

No. Steerglass has no accounts: download it and it works with every cluster and every feature.

Is it really free?

Yes. Steerglass is open source under the Apache 2.0 license: free to use at work and at home, with every cluster and every feature. The code is on GitHub.

Where does Steerglass read my kubeconfig from?

From $KUBECONFIG, ~/.kube/config and the other kubeconfig files in ~/.kube — exactly like kubectl. You can add more files in Settings.

Do the resource charts need anything installed?

They use metrics-server, which GKE, EKS and AKS include by default; elsewhere it's one manifest to apply. Requests and limits come from your pods. metrics-server only knows the current values, so Steerglass keeps the history itself — up to 24 hours — while a cluster is open in the app.

How do updates work?

Steerglass checks steerglass.com for new versions every few hours and offers to install them with one click. Every update is signed with our key, and the app refuses to install one it can't verify — the signing key isn't on the web server, so not even a compromised steerglass.com could push an update. Each release also has SHA-256 checksums. More on the security page.

How can I report a bug or contribute?

Open an issue on GitHub, or use Help → Send feedback in the app: it fills in your version and system. Pull requests are welcome too. For anything else, write to hello@steerglass.com.
