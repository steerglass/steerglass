Install Steerglass

Native app for macOS, Windows and Linux. Pick your system — we guessed it from your browser — and follow the steps.

Homebrew

ONE COMMAND

If you use Homebrew, install Steerglass from our tap. It updates itself; brew upgrade works too.

To uninstall: brew uninstall --cask steerglass (add --zap to remove its settings too).

Download the app

.DMG

One app for Apple Silicon and Intel Macs, signed and notarized by Apple. It updates itself.

Download for Mac
  1. Open the downloaded .dmg.
  2. Drag Steerglass into Applications.
  3. Open it from Applications or Spotlight.

Requirements

macOS 11 Big Sur or laterIncluding the latest macOS
Apple Silicon or IntelOne universal app for both
Your kubeconfig~/.kube/config and $KUBECONFIG, as kubectl
12 MB downloadNative app, no Electron

Installer

RECOMMENDED

Installs Steerglass for your user, no admin rights needed. It updates itself.

Download for Windows
  1. Run steerglass-windows-setup.exe.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway: the installer isn’t code-signed yet. Windows builds will be signed with free code signing provided by SignPath.io, certificate by SignPath Foundation (code signing policy).
  3. Open Steerglass from the Start menu.

Architecture

AppImage

ANY DISTRO

One file that runs on almost any distribution, with everything it needs inside. It updates itself when a new version is out.

Download AppImage

Ubuntu 22.04 and later need FUSE 2 to run AppImages: sudo apt install libfuse2 (on 24.04: libfuse2t64).

Debian, Ubuntu, Mint

APT REPOSITORY

Add the Steerglass repository once: new versions then arrive with apt upgrade, like the rest of your system. Also for Pop!_OS, elementary OS and other Debian-based systems.

Or install the .deb by hand
Download .deb

Fedora, RHEL, openSUSE

DNF REPOSITORY

Add the repository once and update with dnf upgrade. On first install dnf asks to import the Steerglass key: check that the fingerprint matches the one below.

RHEL, Rocky and AlmaLinux 10: enable EPEL first (sudo dnf install epel-release), which provides WebKitGTK 4.1. Version 9 doesn’t ship it: use the AppImage.

openSUSE, or install the .rpm by hand

Verify your download

The app is signed with our Apple Developer ID and notarized by Apple. To check the file: shasum -a 256 steerglass-mac.dmg

The installers aren’t code-signed yet (we are setting up code signing with SignPath Foundation), so SmartScreen may warn you the first time. Check the file before running it, in PowerShell: Get-FileHash .\steerglass-windows-setup.exe

Packages and repositories are signed with the key above. To check a file: sha256sum steerglass-linux-x86_64.appimage

Updates are signed too, and the app refuses any it can’t verify. More on how Steerglass is signed.
