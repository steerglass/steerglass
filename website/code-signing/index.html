Code signing policy

Which Steerglass files are signed, how, and who decides what gets signed. Last updated November 14, 2026.

Windows: free code signing provided by SignPath.io, certificate by SignPath Foundation.

We are setting it up: until it is in place, the Windows installers are not code-signed yet. This page will say so when signed installers are released.

What is signed

FilesSignature
Windows installers (-setup.exe, .msi) and the appAuthenticode, through SignPath.io with a certificate issued to SignPath Foundation.
macOS app and .dmgOur Apple Developer ID (Davide Bettio (79AHY83MQ9)), notarized by Apple.
Linux .deb, .rpm and the apt and dnf repositoriesThe Steerglass repository GPG key (steerglass.asc).
Updates installed by the appAn Ed25519 (minisign) key; the app refuses an update that doesn’t verify. See Security.

How Windows builds are signed

  • Only files built from the source code in our public repository, github.com/steerglass/steerglass, are signed. They are built by GitHub Actions from a release tag, never on a personal machine.
  • Every signing request is approved by hand by an approver (below), one release at a time.
  • Only our own files are signed: files from other projects are never signed with our signature.
  • Every release lists the SHA-256 of its files, on the install page and in sha256sums.txt next to the files.

Team roles

RoleMembers
Committers and reviewersDavide Bettio (maintainer)
ApproversDavide Bettio (maintainer)

Contributions from anyone else are merged only after review by a committer. Every member of the team uses multi-factor authentication on GitHub and SignPath.

Privacy

Steerglass connects directly from your computer to your Kubernetes clusters and doesn’t send anything about them to us or to anyone else. The only other system it contacts is steerglass.com, to check for and download updates. It has no accounts, no telemetry and no crash reporting. The details are in the privacy policy.

Reporting a problem

If you think a signed Steerglass file is not what it should be, write to hello@steerglass.com, or see how to report a vulnerability.
